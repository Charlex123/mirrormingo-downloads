On first launch, choose **MirrorMingo Learning** or **School Intelligence**. You can optionally remember your choice, and switch workspaces from the top bar at any time. Existing account, school-role and subscription checks still apply. On shared computers, leave the automatic choice off and sign out when changing users.

Learning and supported school records retain their existing offline features. Live services, sign-in and payments require an internet connection.

## Install or update

**Mac:** open the downloaded disk image and drag MirrorMingo AI into Applications, replacing the older app.

**Windows:** open the downloaded setup application and follow its installation prompts.

Close the app before replacing an existing installation. App updates currently require installing a new release; cloud data synchronisation does not update the application itself.

The links above always select the latest published installers. Older versions remain available on the [releases page](https://github.com/Charlex123/mirrormingo-downloads/releases).
